# 学段约束（年级 → 学段 → 教学参数）

> 年级 1-6 自动派生学段：低段(1-2) / 中段(3-4) / 高段(5-6)。
> 渲染器据此调字号阶梯、页数建议、 maxY 容量预估；生成 JSON 时据此控制内容密度。

## 页数规律（反直觉：低年级更多）

低年级课件页数反而更多，因为生字教学环节更细致、图片辅助更多。

| 学段 | 课型 | 每课时页数 | 说明 |
|------|------|:---------:|------|
| 低段(1-2) | 精读 | 20-55 页 | 识字细致、图多 |
| 中段(3-4) | 精读 | 15-35 页 | 段落理解为主 |
| 高段(5-6) | 精读 | 15-30 页 | 篇章策略为主 |
| 低段 | 识字课 | 20-40 页 | 游戏巩固多 |
| 低段 | 拼音课 | 15-30 页 | （后续扩展） |
| 任意 | 口语交际 | 10-15 页 | 活动为主 |
| 中高段 | 习作 | 15-25 页 | 导写评改闭环 |

## 各学段识字/写字量（部编版参考）

### 低段（1-2 年级）
- 识字量：约 1600-1800 字
- 写字量：约 800-1000 字
- 朗读：正确、流利，初步有感情
- 重点：识字写字、拼音、词句积累

### 中段（3-4 年级）
- 识字量：约 2500 字
- 写字量：约 1600 字
- 朗读：有感情，初步把握文章主要内容
- 习作：片段练习起步，写清楚一件事
- 重点：段落理解、初步习作

### 高段（5-6 年级）
- 识字量：约 3000 字
- 写字量：约 2500 字
- 朗读：把握文章感情基调，了解表达顺序
- 习作：能写简单的记实作文/想象作文，字数 400 字左右
- 重点：篇章理解、阅读策略、习作

## 生成密度提示

- 低段：生字卡每页 4-6 字、笔画笔顺齐全、多配图、句子简短。
- 中段：段落分析 2-4 段/页、提问深入、开始仿写。
- 高段：篇章策略、读写结合、思辨提问、习作支架。
- 页数不要刻意压缩到下限，优质课件低段常达 30-50 页/课时。
